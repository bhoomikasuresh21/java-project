# java-project
a small min project in java about attendance calculator Student Attendance Calculator

A simple and user-friendly Student Attendance Calculator that helps students calculate their attendance percentage and determine how many additional classes they can miss while maintaining the required attendance.

📌 About the Project

Students often need to keep track of their attendance and know whether they have enough attendance to meet the required percentage.

This project provides a simple solution where the student enters the total number of classes and absent classes. The application then calculates the attendance and displays the results clearly.

✨ Features

- Enter total number of classes
- Enter number of absent classes
- Automatically calculate attended classes
- Calculate attendance percentage
- Calculate additional leaves allowed
- 75% minimum attendance check
- Warning when attendance is below 75%
- Input validation
- Clear/reset option
- Simple and professional user interface
- Responsive design

🧮 Calculation

Attended Classes

Attended Classes = Total Classes - Absent Classes

Attendance Percentage

Attendance Percentage =
(Attended Classes / Total Classes) × 100

Additional Leave

The application calculates how many additional classes can be missed while keeping attendance at or above 75%.

🖥️ Example

If a student has:

Total Classes   = 100
Absent Classes  = 20

Then:

Attended Classes       = 80
Attendance Percentage  = 80%

The application also displays the number of additional classes that can be missed while maintaining 75% attendance.

🚀 How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Run it using a browser or VS Code Live Server.
5. Enter the total and absent classes.
6. Click Calculate Attendance.
